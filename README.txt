SMART NEXT CANDLE BOT V1.1 · BINOMO SCREENSHOT UPGRADE
======================================================

START HERE
1. Open index.html in Chrome or another modern browser.
2. The default first tab is "Binomo Screenshot".
3. Tap "Upload Binomo Screenshot" and select a JPG/PNG/WebP from your Photos
   or Files. Optionally, use "Paste Screenshot" or long-press the paste field
   on iPhone Chrome and select Paste if supported by your browser.
4. The image is analyzed automatically. Green/red candle bodies are detected
   inside the outlined chart area. Drag to choose a tighter chart area if
   the count or direction looks wrong. "Reset Chart Area" restores default.
5. Toggle "Rightmost visible candle is still moving" to specify whether
   the last visible candle was unfinished when the screenshot was taken.
6. UP/DOWN is a rough COLOR/SHAPE-ONLY visual bias for the candle after
   the pictured last candle. It is NOT a live price-based prediction.

CRITICAL LIMITATIONS
- One static screenshot CANNOT monitor live movement, verify chart time,
  or reconstruct reliable numerical OHLC data, RSI/MACD or trade outcomes.
- It DOES NOT connect to the Binomo platform. Screenshot analysis updates
  only when you paste/upload a NEW screenshot.
- Auto-detection can mistake colored labels/indicators/price lines for
  candles; manually frame only the candlestick chart and inspect count.
- The next-candle start time is marked Unknown in screenshot mode because
  the capture time and candle boundary cannot be authenticated.
- Signal strength /100 is NOT win probability; NO trading orders are placed.
- The tool is a transparent rule-based image heuristic, NOT a trained AI.
- For educational and DEMO review ONLY, not real-money binary options.
