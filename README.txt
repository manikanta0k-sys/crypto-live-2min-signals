Crypto IDX 5-Minute Screenshot Outlook V3

1. Open index.html in iPhone Chrome or a desktop browser.
2. Paste screenshot or tap Upload and select a Binomo Crypto IDX 1m screenshot.
3. The image is analyzed automatically; no Analyze & Close screen.
4. Main view shows UP / DOWN / WAIT bias, and a 5-minute target start/end.
5. By default, the next window starts when the current one-minute candle ends. In gear settings you can instead choose a full 5m exchange-style candle aligned to 5-minute marks.
6. Source chart is 1m; the direction describes total CLOSE versus OPEN over the target 5-minute window, NOT each of its five 1m candles.
7. Running candle is excluded. 20+ completed 1m candles required. 18 inherited indicator checks + 4 advanced checks + 32 candlestick pattern checks included.
8. The screenshot candle recognition uses unverified approximate pixel OHLC. This is NOT the official Binomo price feed. Screenshot time is not read from the image. Source file modification time or paste receipt time is used; historical images must not be considered live.
9. Signals can be inaccurate, especially at a 5-minute horizon. Use only DEMO to compare estimates with actual results. No automated trading and no win-rate guarantees.
10. If browser clipboard access is blocked on iPhone Chrome, the Paste button opens Photos; selecting an image still runs the analysis immediately.
